# ADR-004 资产不分发

状态：已接受（Accepted）

## 背景
MMD 模型/动作/音频/借用贴图多为第三方资产，可能受版权或授权限制；仓库分发这些实体文件既不必要也有合规风险。

## 决策
仓库与发布包**不包含**任何 PMX/VMD/音频/借用贴图实体文件。测试与金标只用自生成的合成样本。

## 影响
- `.gitignore` 排除 `*.pmx`、`*.vmd`、`*.pmm`、`*.wav`、`*.mp3`、`*.tga`、`*.bmp` 及 `samples/private/`（约束 C5）。
- 门禁第 5 步做资产泄漏检查（含 samples/ 与合成样例生成器的逐字节比对）。
- 真实样本（如黑羽 PMX）仅供本地标定，不进入仓库（未决项 U2）。

## 参考 / 借鉴范围
- 思路来源：开源项目「分发源码、不打包第三方资产」的通用合规实践（如 MMD2Unreal 将模型资产排除在仓库外）。
- clean-room 声明：不复制任何第三方代码；本 ADR 仅确立资产边界策略。
- 许可核实指向 ADR-003。
