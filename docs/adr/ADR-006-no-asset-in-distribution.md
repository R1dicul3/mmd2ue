# ADR-006 工具定位：纯转换器，零资产分发

状态：已接受（Accepted）

## 背景
用户于 2026-10-29 明确工具的根本定位边界，作为第二阶段及之后所有阶段的硬约束。

## 决策
1. **工具本身不包含任何模型数据**：仓库、分发包（sdist/wheel）、任何产物目录中，均不包含 PMX/VMD/VPD/纹理/音频/参数等实体资产。
2. **工具只做转换**：输入用户的本地 MMD 资产，输出 UE 5.8 可用的转换产物；工具不内置、不附带任何用于对照或展示的模型本体。
3. **分发仅含工具自身代码**：对外发布时只打包源码与文档，附带的最小合成样例（samples/）仅作为测试夹具存在，且随包分发——它们由 gen_samples.py 程序化生成，非任何借用的模型数据。

## 与既有约束的关系
- 强化 C5（资产边界）：C5 约束仓库不含实体资产；本 ADR 进一步扩展到「分发包与任何产物」，并排除「分发附带模型对照物」的歧义。
- 不影响测试：合成样例（gen_samples.py 输出）是工具自己生成的程序化夹具，不属于「模型数据」，仍可用于金标与单测。
- 不影响真实资产标定里程碑：真实黑羽资产标定（AC-M0-2/3/4、AC-M1-1/2）发生在本地开发侧，产物仅落 tools/calibrate/results/ 下的数值 JSON（不含模型本体），不随分发。

## 影响
- 资产泄漏门禁（verify_all.py step5）持续生效，且发布打包工具未来需加入「产物 tree 不含实体资产」校验。
- README / LICENSE / 分发清单须声明「本工具不含任何模型数据，模型/动作/音乐的授权由使用者自行负责」。
